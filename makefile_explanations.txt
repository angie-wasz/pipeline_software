MAKEFILES for mwa-solar pipeline to get final scintillation levels

"-j 2" multitasks 2 tasks at a time if make says that the jobs can be run at the same time


Makefile.posinterp

interpet positions
we have a super pixelated image to reduce our hdf5 size
aegean sometimes doesnt work perfectly with this, so this section will take any sources that are too pixelated and interpolate their position properly
this is run for both the continuum and moment images

interpt moment2 positions
looks at all the sources in the contiuum image, takes the position from the contiuum, maps it to that position in the moment2 then interpolates the surrounding pixels to get the brightness

tidy up catalogs:
gets rid of columns we dont need (23 columns)
    - all the columns that end in _2 are all the corresponding measurements from the moment2 image
    - pbcor (primary beam correction)
        pbcor is less than 1 everywhere
        pbcor_norm is the centre of the beam, need this to get the half power point
adds in columns that we do need, such as solar elongation
adds in beam information (important!)
    - this is the only information that we need the hdf5 file for at this point in the process
    - going to try and add in make_cat.py into the imaging pipeline to extract the beam information from the hdf5 there and add it into the catalogues (the comp.vot files) and then we never have to look at the images or the hdf5 file again, and we complete the rest of the processing in catalogue space
        - this may be too difficult, so we'll just cut down the hdf5 to only contain the beam information




Makefile.ion

removes the refraction of source position caused by the ionosphere
end up with an ra_corr and dec_corr, which is just the adjustment for the ionosphere
- we use these for the rest of the process since these are the actual correct positions



Makefile.gleam

1. looking through the full gleam catalogue, and seeing what sources are in our half power point
everything else gets thrown away

2. cross match the above list with our stuff to see what gleam sources are detected in our continuum image
throw away everything that isn't in gleam

3. figure out the NSI for each of those detections
adds in mpoint1 and 2 so useful for me

4. 5. throw away everything that is in the moment2 but not in the continuum

6. digest, cleans up and keeps only the columns that are useful to us




Run all those makefiles one after another and spits out ${obsid}_gleam_digest.fits
this is the final catalogue file which has all the infomation to get g-levels

what to do to add the g-level into fits (goes into Makefile.glevel as stilts commands)

1. cross match with /data/ips/catalogs/ips_dr2_230324.fits
    - Exact match
    - from digest.fits column GLEAM
    - from dr2.fits column GLEAM
    - Best match for each Table 1 row
    - join type both 1 and 2

COMMAND: topcat -stilts tmatch2 out=cross_match.fits ofmt=fits matcher=exact values1=GLEAM values2=GLEAM join=1and2 find=best1 in1=1363311312_gleam_digest.fits in2=/data/ips/catalogs/ips_dr2_230324.fits

NON-SPECIFIC COMMAND:

topcat -stilts tmatch2 out=${dir}/cross_match.fits ofmt=fits matcher=exact values1=GLEAM values2=GLEAM join=1and2 find=best1 in1=${dir}/${obsid}_gleam_digest.fits in2=/data/ips/catalogs/ips_dr2_230324.fits

where
dir=/data/awaszewski/ips/feb_cme/2023/{obsid}/
obsid=1363311312

2. remove all columns from Table 2 apart from nsi_fit and nsi_err (can skip this step, doesn't really take up too much room)
    - GLEAM
    - RAJ2000
    - DEJ2000
    - s_162
    - elongation
    - class
    - ul_fit
    - ul_err
    - l_0
    - l_1
    - s_cont_lim
    - s_5lim
    - n_fit
    - n_eff


3. add in g column into crossmatch table match(1,2)
    - expression: dS2 / (peak_flux*mpt2*nsi_fit)

4. add in snr_g column into crossmatch table match(1,2)
    - expression: nsi_fit*mpt2*peak_flux/local_rms2

Combine steps 3 and 4

COMMAND: topcat -stilts tpipe cmd='addcol g dS2/(peak_flux*mpt2*nsi_fit)' cmd='addcol snr_g nsi_fit*mpt2*peak_flux/local_rms2' omode=out ofmt=vot out=${dir}/${obsid}_glevel.vot in=${dir}/cross_match.fits

6. save table as {obsid}_glevel.vot (make sure it is a votable) (moved to combine as out file)
